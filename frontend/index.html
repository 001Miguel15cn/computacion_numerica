Polinomio de Taylor

Aproximación de funciones mediante derivadas sucesivas

¿Qué es el polinomio de Taylor?

Aproxima una función f(x) usando sus derivadas en un punto a. A mayor grado, mejor la aproximación cerca de ese punto. El resto de Lagrange acota el error máximo.

\[ P_n(x) = f(a) + f'(a)(x-a) + \frac{f''(a)}{2!}(x-a)^2 + \cdots + \frac{f^{(n)}(a)}{n!}(x-a)^n \]
Parámetros

Cambio de base

Conversión entre decimal, binario, octal y hexadecimal

¿Cómo funciona?

Para convertir un entero a base b: dividir sucesivamente por b y leer los residuos de abajo hacia arriba. Para fracciones: multiplicar por b y extraer la parte entera en cada paso.

42 ÷ 2 → residuos: 0 1 0 1 0 1 → leer al revés: 101010₂

Ecuaciones no lineales en una variable

Encuentra raíces de f(x) = 0

Bisección vs Newton-Raphson

Bisección: divide el intervalo [a,b] a la mitad. Requiere cambio de signo. Convergencia lineal — lento pero seguro.
Newton-Raphson: usa la tangente para iterar. Convergencia cuadrática — muy rápido cerca de la raíz, pero puede divergir si x₀ es malo o f′≈0.

Sistemas de ecuaciones no lineales

Método de Newton para sistemas 2×2 — la Jacobiana se calcula automáticamente

Newton para sistemas

En cada iteración se evalúa el vector F y la Jacobiana J (derivadas parciales, calculadas simbólicamente). Se resuelve J·Δ = −F y se actualiza el punto. Converge cuadráticamente cerca de la solución.

\[ \mathbf{x}_{k+1} = \mathbf{x}_k - J^{-1} F(\mathbf{x}_k) \]
Sistema F(x,y) = 0

Interpolación de Lagrange

Polinomio que pasa exactamente por n+1 puntos

¿Qué es?

Dado n+1 puntos (xᵢ, yᵢ), existe un único polinomio de grado ≤ n que los interpola. La forma de Lagrange construye bases Lᵢ(x) que valen 1 en xᵢ y 0 en los demás nodos.

\[ P(x) = \sum_{i=0}^{n} y_i L_i(x), \quad L_i(x) = \prod_{j \neq i} \frac{x - x_j}{x_i - x_j} \]
Puntos y evaluación

Diferencias divididas de Newton

Construcción incremental del polinomio interpolante

¿Qué son?

Dan el mismo polinomio que Lagrange pero de forma incremental: agregar un nuevo punto solo requiere una nueva columna en la tabla. Los coeficientes son las diferencias divididas de la primera fila.

\[ P(x) = f[x_0] + f[x_0,x_1](x-x_0) + f[x_0,x_1,x_2](x-x_0)(x-x_1) + \cdots \]
Puntos y evaluación

Polinomio de Taylor — 2 variables

Aproximación de f(x,y) en un punto (a,b) usando derivadas parciales

Expansión de Taylor en 2 variables

El polinomio de orden 2 alrededor del punto (a,b) usa las derivadas parciales de primer y segundo orden. Cuánto más cerca estés de (a,b), mejor la aproximación.

\[ P(x,y) = f(a,b) + f_x\Delta x + f_y\Delta y + \frac{1}{2!}\left(f_{xx}\Delta x^2 + 2f_{xy}\Delta x\Delta y + f_{yy}\Delta y^2\right) \]

Las derivadas parciales se calculan simbólicamente con SymPy. Δx = x−a, Δy = y−b.

Ajuste de curvas — Mínimos cuadrados

Encuentra la curva que minimiza la suma de cuadrados de residuos

Mínimos cuadrados

Dado un conjunto de puntos (xᵢ, yᵢ), se buscan los parámetros del modelo que minimizan Σ(yᵢ − ŷᵢ)². El sistema de ecuaciones normales se resuelve por eliminación gaussiana. El coeficiente R² mide la bondad del ajuste (1 = perfecto).

\[ \min \sum_{i=1}^{n}(y_i - \hat{y}(x_i))^2 \qquad R^2 = 1 - \frac{SS_{res}}{SS_{tot}} \]

Ajusta y = a₀ + a₁x con las fórmulas directas del sistema normal 2×2.

\[ a_1 = \frac{n\sum x_iy_i - \sum x_i\sum y_i}{n\sum x_i^2 - (\sum x_i)^2}, \quad a_0 = \frac{\sum y_i - a_1\sum x_i}{n} \]
Datos

Ajusta y = a₀ + a₁x + a₂x² (o grado 3) resolviendo AᵀA·c = Aᵀy por eliminación gaussiana con pivoteo.

\[ \min \sum_{i=1}^{n}\!\left(y_i - \sum_{k=0}^{m}a_k x_i^k\right)^{\!2} \]
